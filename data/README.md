# بيانات التدريب

ضع هنا نصوصاً تملك حق استخدامها. التدريب يقرأ كل ملفات `.txt` تحت المجلد الذي تمرره إلى `train.py` (الافتراضي `data/corpus`).

- `corpus/`: البذرة الأصلية المرافقة للمشروع، ويمكن استبدالها أو الإضافة إليها.
- `private/`: مكان مقترح لبيانات لا تريد رفعها إلى Git.
- الترميز المطلوب: UTF-8.
- التفاصيل والسجل: [SOURCES.md](SOURCES.md).
